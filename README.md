# HTML ID Extractor - Streamlit

## Deploy to Streamlit Community Cloud

Upload this folder to GitHub and connect the repository to Streamlit Community Cloud.

Main file:
`app.py`

The application:
- accepts one or more URLs
- extracts IDs beginning with `link_`
- captures screenshots of matching elements
- previews screenshots
- downloads extracted IDs as TXT
- downloads screenshots and TXT files as ZIP

## Files

- `app.py` - Streamlit application
- `requirements.txt` - Python dependencies
- `packages.txt` - Linux dependencies
- `.streamlit/config.toml` - Streamlit configuration
